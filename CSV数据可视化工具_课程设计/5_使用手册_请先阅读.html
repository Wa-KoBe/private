第一章 项目概述

1.1 项目简介

CSV 数据可视化工具是一个基于 C 语言 的命令行工具，能够读取标准的 CSV 格式数据文件，提供交互式数据可视化分析，并支持生成专业的 HTML 报告。

1.2 核心功能

  • 📂 CSV 数据解析 — 自动识别表头、数据类型（数字/文本）
  • 📊 柱状图 — 频次分布可视化，颜色随数值渐变
  • 📈 折线图 — 数据趋势变化展示
  • 🥧 饼状图 — 占比分布圆形图表
  • 📋 统计摘要 — 均值、中位数、标准差等关键指标
  • 📄 HTML 报告 — 一键生成带交互特效的数据报告
  • 📝 文本报告 — 生成可阅读的 txt 报告文件

1.3 技术特点

  • 纯 C 语言实现，轻量高效
  • 支持中文字段名（UTF-8 编码）
  • 智能列类型识别（自动区分数字列与文本列）
  • 交互式菜单操作，简单易用
  • 命令行参数支持，可集成到自动化流程

3.2 CSV 数据格式说明

数据文件采用标准 CSV 格式，要求：

  • 第一行为字段名（表头）
  • 每行一条数据记录
  • 字段间用逗号 , 分隔
  • 支持中文表头和数据
  • 数值列会自动识别为"数字"类型
示例 
学号,姓名,高数,英语,C语言,总分
2024001,张伟,92,85,88,265
2024002,李娜,76,90,95,261
...

第七章 代码结构说明

7.1 项目架构

csv_viz3.c            — C 主程序（交互式 + 命令行）
├── CSV 解析器        — 读取、解析 CSV 文件
├── 类型检测器        — 自动识别数字/文本列
├── 统计计算器        — 均值、中位数、标准差等
├── 柱状图引擎        — 频次分布条形图
├── 折线图引擎        — 趋势折线图（Bresenham）
├── 饼状图引擎        — 扇形分布图（视窗适配）
├── 文本报告生成器    — 输出 txt 格式报告
└── 菜单系统          — 交互式命令行界面

report_html.py        — Python HTML 报告生成器
├── CSS 样式          — 渐变背景、动画、交互效果
├── JavaScript         — 滚动放大、视差、进度条
├── 数据概览模块      — 字段表格、统计卡片
├── 统计摘要模块      — 数值指标卡片网格
└── 图表生成模块      — 柱状图（频次+占比）

成绩表.csv            — 测试数据（40条学生成绩）

7.2 技术要点

技术点实现方式
CSV 解析逐行读取 + 逗号分割 + 引号处理
类型识别尝试将每列转为浮点数，全部成功则为数字列
柱状图自动分6段 + 等距区间 + 比例缩放
折线图线性插值 + 斜率字符选择（/-\\|）
饼状图极坐标映射 + 宽高比修正 + 字符扇区
编码UTF-8 + Windows API 设置控制台编码

第八章 常见问题

Q1: 程序启动后闪退怎么办？

请确保在 cmd 中运行，或先关闭已打开的旧版本程序再重新打开。

Q2: 中文显示乱码？

程序已自动设置 UTF-8 编码。若仍有乱码，请在 cmd 中运行：chcp 65001 后再启动程序。

Q3: 为什么所有列都显示为"文本"？

检查 CSV 文件是否包含 BOM 头部，或数据中是否有非数字字符（如空格、特殊符号）。

Q4: HTML 报告如何保存为 PDF？

在浏览器中打开报告，按 Ctrl + P，选择"另存为 PDF"即可。

Q5: CSV 文件应该用什么编码？

推荐使用 UTF-8 编码保存 CSV 文件。如果使用 Excel 导出，请选择"CSV UTF-8"格式。

Q6: 如何自己编译源码？

gcc csv_viz3.c -o csv_viz.exe -lm

Q7: 报告中的标题乱码怎么办？

程序通过 _title.txt 文件传递标题，避免命令行编码问题。如果仍有问题，请直接编辑 _title.txt 文件后运行：python report_html.py 成绩表.csv --output report.html
