# CSV 数据可视化工具  
  
> > 课程设计项目 —— 用 C 语言实现 CSV 文件可视化分析，并生成 HTML 报告。  
  
## 项目结构  
  
- 1_主程序_csv_viz.exe：编译好的可执行程序  
- 2_源代码_csv_viz3.c：C 语言源代码  
- 3_HTML报告生成器_report_html.py：HTML 报告生成脚本  
- 4_示例数据_成绩表40人.csv：示例数据（40人成绩表）  
- 5_使用手册_请先阅读.html：使用说明文档  
  
## 功能说明  
- 读取 CSV 格式的数据文件  
- 对数据进行统计与分析  
- 生成可视化的 HTML 报告页面  
- 支持自定义数据导入  
  
## 使用方法  
直接运行 1_主程序_csv_viz.exe 即可启动，或使用 GCC 编译 C 源代码  
运行 python 3_HTML报告生成器_report_html.py 可生成可视化报告  
  
## 技术栈  
- 语言：C、Python  
- 数据格式：CSV
